FIELD RUNTIME GUIDE

          SYNTAX, OPERATORS & VISUAL NAVIGATION
        

        
      

      

        

          
1. UNIFIED FIELD SPECIFICATION SYNTAX

          
Declare the field, operations, view representation, and spatial sampling in a single unified script:

          
field {
  expr: sqrt(x*x + y*y + z*z) - 1.8
  domain: x[-4:4] y[-4:4] z[-4:4]
}
view {
  shells { [-0.4, 0.0, 0.4] }
}
sample {
  res: 48
  box: x[-4:4] y[-4:4] z[-4:4]
}

3. NESTED WIREFRAME SHELLS

          
Isosurfaces render as nested wireframe shells over the sampled domain with no polygon faces, no lighting, and no shading. Line weight and opacity differentiate inner and outer shells.

        


        

          
4. DUAL CONTROLLERS & JOG PADS

          
    
            
  • LEFT PAD (BOX): Controls the sampling domain box. Drag disk for XY planar translation, drag vertical slider for Z-axis shift. Double-tap to reset box position.
    • 
            
  • RIGHT PAD (CAM): Controls camera viewpoint. Drag disk to orbit azimuth and elevation, drag vertical slider to zoom/dolly. Double-tap to reset view.
    • 
            
  • PROBING: Click anywhere on the 3D field to measure exact localized scalar/vector values at that coordinate.
    • 
          

        


        

          
5. SHORTCUTS

          
    
            
  • Ctrl + Enter / Cmd + Enter: Immediately evaluate & render field.
    • 
            
  • Ctrl + Space: Trigger syntax autocompletion popup.
    •
