Field Runtime Guide

Syntax, Operators & Visual Navigation

1. Unified Field Specification Syntax

Declare the field, operations, view representation, and spatial sampling in a single unified script:

field {
  preset: radial           # or expr: "sin(x)*cos(y)"
  domain: x[-4:4] y[-4:4] z[-4:4]
}
ops {
  gradient                 # ∇f (or divergence, curl, laplacian)
}
view {
  iso { level: 0.0 color: #1D4ED8 opacity: 0.9 }
  streamlines { seeds: 48 steps: 150 cmap: viridis }
}
sample {
  res: 48
  box: x[-4:4] y[-4:4] z[-4:4]
}

3. Custom Vectors & Discrete Fields

Vector Fields: Use bracket notation in the expr field to define 3D vectors: expr: [sin(y), cos(x), 0.5*z].

Discrete Fields (Grids): You can bake an analytic function into a discrete voxel grid to simulate numpy/CSV arrays by adding the bake operator: ops { bake { res: 64 } }.

4. Dual Controllers & Jog Pads

  • Left Pad (BOX - Amber): Controls the sampling domain box. Drag disk for XY planar translation, drag vertical slider for Z-axis shift. Double-tap to reset box position.
  • Right Pad (CAM - Blue): Controls camera viewpoint. Drag disk to orbit azimuth and elevation, drag vertical slider to zoom/dolly. Double-tap to reset view.
  • Pinch & Touch: Full touch screen support with multi-touch pinch to zoom and touch-drag.
  • Probing: Click anywhere on the 3D field to measure exact localized scalar/vector values at that coordinate.

5. Code Editor & Shortcuts

  • Ctrl + Enter or Cmd + Enter: Immediately evaluate & render field.
  • Ctrl + Space: Trigger syntax autocompletion popup.
  • Tab: Indent 2 spaces / accept completion.
  • Esc: Close dropdowns or modal dialogs.
